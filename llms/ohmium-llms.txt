# Ohmium

> Ohmium International designs, manufactures and deploys modular, vertically-stackable proton exchange membrane (PEM) electrolyzer systems for green hydrogen production. Its Lotus PEM electrolyzer platform (Mark 3) integrates power electronics, water treatment and controls into skid-mounted modules for industrial, energy and mobility customers, delivered alongside EPC and remote monitoring and maintenance (RM&M) services.

## No public API

Ohmium publishes **no public developer program**. As of 2026-08-04 there is no developer portal,
no API reference, no SDK, no webhook catalog and no machine-readable specification (OpenAPI,
AsyncAPI, GraphQL SDL, Postman collection) on any Ohmium host. Contract discovery probed
`www.ohmium.com`, `ohmium.com` and every certificate-transparency-discovered subdomain for
`/openapi.json`, `/swagger.json`, `/api-docs`, `/graphql`, `/llms.txt` and the full
`/.well-known/*` set; every path returned 404 or an HTML single-page-app shell.

The software surfaces that do exist on Ohmium subdomains are third-party SaaS products or
login-gated internal applications, not an Ohmium API:

- `canary.ohmium.com` — Axiom, a third-party operational historian by Canary Labs (the RM&M
  monitoring view). Vendor product, not an Ohmium API.
- `workspace.ohmium.com` — Freshworks, hosted on an Ohmium custom domain.
- `help.ohmium.com` — Ohmium Service Desk (Freshdesk).
- `leadtime.ohmium.com` — "Ohmium · Lead Time Guide", an Azure Static Web App whose
  `/api/*` routes return `401 Unauthorized` (Azure Static Web Apps auth). No published contract.
